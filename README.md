# FexCore — Plataforma de Mantenimiento Industrial Inteligente

Sitio web corporativo e interactivo para **FexCore**, un SaaS B2B de Mantenimiento Industrial (CMMS) diseñado para erradicar el caos operativo, optimizar la gestión de activos y reducir tiempos muertos en plantas de producción.

## 🚀 Stack Tecnológico

- **Framework**: Next.js 14+ (App Router) con React & TypeScript
- **Estilos**: Tailwind CSS
- **Animaciones**: Framer Motion (transiciones, scroll reveals, levitación de tarjetas)
- **Iconografía**: Lucide React
- **Multilingüe**: Internacionalización nativa (ES/EN) con selector dinámico en el Navbar

## 🌟 Características Principales

1. **Navbar Sticky**: Glassmorphism con indicador de navegación y toggle ES/EN.
2. **Hero Section**: Dashboard mockup interactivo con feed en vivo, gráficos de Uptime (+99.8%) y métricas de ROI.
3. **Logo Marquee**: Carrusel infinito de logos interactivo.
4. **Audience Section**: Secciones enfocadas para Directores de Planta, Jefes de Mantenimiento y Operadores.
5. **Solutions Grid**: Cuadrícula 2×2 con detalles técnicos de trazabilidad, IoT y mantenimiento preventivo.
6. **Testimonials**: Casos de éxito empresariales y calificaciones de clientes.
7. **Contact Form**: Formulario interactivo para solicitud de Demo con selección de número de máquinas.
8. **Footer**: Enlaces de navegación, redes y Operational Status en tiempo real.

## 🛠️ Instalación y Desarrollo Local

```bash
# Clonar repositorio
git clone https://github.com/Giuseppe152004/fexcore.git

# Entrar al directorio
cd fexcore

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la aplicación.
